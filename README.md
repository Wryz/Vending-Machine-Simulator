# Coinline — Vending Machine Simulator

A real-world-map vending tycoon for iPhone (Android-ready), built with Expo (dev build), TypeScript, MapLibre and React Three Fiber. See [`SPEC.md`](SPEC.md) for the product spec and [`docs/spikes/M1-REPORT.md`](docs/spikes/M1-REPORT.md) for the build status, spike findings and decisions.

## Layout

| Path | What |
|---|---|
| `app/` | expo-router screens: onboarding, map, Spot Card, contract, 3D close-up, key ring, routes, company, collections, cities, shop, report, settings, credits, diagnostics |
| `src/sim/` | Pure, deterministic game simulation (no React/IO). 100% of game rules live here, with unit tests |
| `src/config/` | All tunable numbers: economy, machines, products, places, curves, progression, cities, climate, holidays, map, time of day |
| `src/data/` | API client, h3 (with Hermes TextDecoder shim), city pack loader, weather |
| `src/map/` | MapLibre style builder, time-of-day interpolation, sprite selection, map↔3D camera matching, `CityMap` |
| `src/three/` | Procedural low-poly machine model, sun-driven lighting rig, R3F `MachineScene` |
| `src/ui/` | Physical-object UI: receipt, clipboard, key tags, coin tray, contract sheet, permit card, spec tag |
| `src/store/` | Zustand stores (game, profile) + local JSON persistence |
| `src/services/` | Ads (rewarded only), purchases, notifications, haptics, audio, analytics |
| `assets/cities/` | Bundled city packs for the 9 fallback cities (generated by `pipeline/`) |
| `assets/sprites/`, `assets/models/`, `assets/audio/` | Generated by `scripts/` |
| `workers/data-api/` | Cloudflare Worker: area check, region/city packs, weather proxy, PMTiles tiles |
| `pipeline/` | Offline data pipeline: OSM (Protomaps build) → H3 res-9 city packs |

## Develop

```bash
npm install
```

```bash
npm run typecheck && npm run lint && npm test
```

The app needs a **development build** (native modules: MapLibre, expo-gl, ads, purchases). Build one with EAS:

```bash
npx eas-cli@latest build --profile development --platform ios
```

Then start Metro and open the dev build on the phone:

```bash
npm start
```

### Configuration (`EXPO_PUBLIC_*`, see `src/data/env.ts`)

| Variable | Purpose |
|---|---|
| `EXPO_PUBLIC_DATA_API_URL` | Optional Data API Worker base URL (area check, shared weather cache, region packs, self-hosted tiles). Without it the app still works: tiles from OpenFreeMap, weather straight from MET Norway |
| `EXPO_PUBLIC_TILES_URL` | Optional self-hosted tiles: a `.pmtiles` URL (native `pmtiles://`) or an XYZ template with `{z}/{x}/{y}`; `{name}` is replaced by the city id. Empty = OpenFreeMap (free, no key) |
| `EXPO_PUBLIC_TILES_SCHEMA` | `protomaps` (default for self-hosted) or `openmaptiles` |
| `EXPO_PUBLIC_REVENUECAT_IOS_KEY` / `_ANDROID_KEY` | Enables the store (one-time purchases) |
| `EXPO_PUBLIC_ADMOB_REWARDED_IOS` / `_ANDROID` | Rewarded ad units (dev builds fall back to Google test ids; release builds hide ads without them) |
| `EXPO_PUBLIC_POSTHOG_KEY` | Optional privacy-light analytics (event counts only) |

Replace the Google **test** AdMob app ids in `app.json` before release.

### Data API

```bash
cd workers/data-api && npm install && npm test
```

```bash
cd workers/data-api && npx wrangler dev
```

Upload city packs and tiles to the R2 bucket `coinline-data` (see `workers/data-api/README.md`).


```bash
node scripts/audio/generate.mjs
```

```bash
cd pipeline && npm install && npx tsx build-city.ts new-york
```

## Free services

Map tiles come from **OpenFreeMap** and weather from **MET Norway**. Both are free, need no key, and allow commercial use with attribution. See [`docs/hosting.md`](docs/hosting.md) for terms, limits and the self-hosting fallback (Cloudflare R2 free tier).
